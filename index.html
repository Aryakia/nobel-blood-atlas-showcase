Research rules

Evidence before inference.

Never infer blood type from nationality, ancestry, personality, name, appearance, or any proxy.
A laureate enters the analytical evidence set only when a source explicitly connects that individual to a blood type.
Conflicting claims stay visible and are excluded from calculations until resolved.
Population comparisons are contextual; the observed sample is sparse and non-random.

Technical architecture

Built for reviewable research data.

The working application uses Next.js 16, React 19, TypeScript, Cloudflare-compatible delivery, D1, and Drizzle ORM. Evidence submissions enter a review workflow rather than modifying the published analytical dataset automatically.

Disclosure boundary

Public method, private operational data.

The showcase excludes source code, live database contents, submitted contact information, pending evidence, credentials, deployment bindings, environment configuration, and internal review material.
