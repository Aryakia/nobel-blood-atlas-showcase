# Contributing public evidence

Contributions should improve the **public evidence trail**, not expand speculation.

A useful contribution should include:

- the laureate's full name;
- the exact source URL;
- the blood type stated by the source;
- the source type (interview, biography, reputable report, blood-service material, etc.);
- where in the source the claim appears;
- any known contradictory source.

Please do **not** submit private medical records, personal contact information, leaked material, inferred blood types, or claims based on nationality, ancestry, personality, name or appearance.

Because GitHub issues are public, only submit material that is already appropriate for public research review.
