# Legacy ChatGPT Sites / Next.js source archive

This directory preserves the core source of the earlier Nobel Blood Atlas application before the project was migrated to a static GitHub Pages implementation on 3 October 2026.

## Preserved

- main React/Next.js dashboard source;
- complete legacy responsive stylesheet;
- root metadata/layout;
- evidence-submission API route;
- D1/Drizzle schema and connection helper;
- package manifest and TypeScript/Vite/Next configuration;
- data-validation script.

## Intentionally not preserved

The archive does **not** include live D1 database contents, visitor contact information, pending evidence submissions, credentials, environment secrets, ChatGPT Sites project bindings, or other deployment-specific private state.

The active public application is the static site at the repository root. This archive is retained only so the earlier implementation is not lost if the former private repository is later deleted.
