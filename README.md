# Nobel Blood Atlas — Public Showcase

**An evidence-graded research dashboard for exploring publicly reported Nobel laureate blood types while keeping missing data, contradictory claims, and documentation bias visible.**

**Repository type:** Public project showcase  
**Project area:** Evidence mapping · data quality · research dashboard  
**Working source:** Private  
**Status:** Research prototype

---

## Project overview

Nobel Blood Atlas explores a difficult data-quality problem: blood-type information for Nobel laureates is sparse, inconsistently reported, and affected by strong documentation bias.

Instead of treating the available records as a complete dataset, the project makes evidence quality and missingness part of the analysis itself.

## Research principles

1. Blood type is never inferred from nationality, ancestry, personality, name, or appearance.
2. A laureate enters the dataset only when a source explicitly connects that person to a blood type.
3. Conflicting claims remain visible and are excluded from calculations until resolved.
4. Population comparisons are contextual and should not be interpreted as biological conclusions from the current sparse sample.

## What I built

- Nobel Prize category filters
- Observed-versus-expected ABO comparisons
- Separate views for screened claims and corroborated reports
- Searchable evidence ledger
- Evidence grades and source links
- Contradiction tracking
- Selected population baselines
- Documentation-bias warnings
- Research queue for unknown and unresolved records
- Downloadable versioned dataset
- Evidence-submission workflow
- Methodology and sensitivity guidance

## Why it matters

The project is as much about **how to reason with incomplete evidence** as it is about blood types. Uncertainty, provenance, contradiction, selection bias, and missingness remain visible throughout the interface rather than being hidden behind a single chart.
